1. Unzip trendbot.zip, run npm install
2. Run node bot.js
3. Open http://127.0.0.1:8787
4. Wallet tab → paste your family seed → Import
Paste your XRPL family seed (starts with s). It goes only to this local bot, is held in memory, and is never saved or logged.
Importing switches the bot from paper to live mainnet trading on the selected pair, with Auto on. Turn Auto off first for manual control.
